So, clicking objects is *objectively* great (see what I did there?)
But what about holding them?
If our players can pick up objects, we can make them put them down where we want them to! That means we can do A LOT of different puzzles:
- Put the 3 items in the correct spot
- We can make our players actually physically pick up a key and bring it to the door
- I can't think of more right now, but I promise they exist!

So how does it work?
Essentially, we're going to use our raycast to do a "click and hold" on objects. While the player is holding the mouse button, we'll hold the item. When they let go, we'll drop the item.
A few notes though!
- I've built this to pick up **RigidBody3Ds**
	- This means that these objects use Gravity. We'll need to turn the gravity off while we're holding it, and turn it back on when we let go
- To make it follow us, I'm going to make a **Hold Point**
	- This is just going to be a Marker3D that we'll put onto our player. We'll parent the object to our Hold Point when we pick it up, and un-parent it when we let it go.
	- As long as it's parented to our player, it will go where the player goes.

Now, lets give our Object a script:
```gdscript
extends RigidBody3D
class_name Holdable

var orig_scale : Vector3
@export var shrink_scale : Vector3  = Vector3.ONE

func _ready():
	orig_scale = scale

func shrink():
	scale = shrink_scale
	
func embiggen():
	scale = orig_scale

```
>[!NOTE]- Do you like comic book references?
>"Embiggen" is a Ms Marvel reference, a term Kamala used in her very first issue, Ms Marvel #1 from 2014.  Great comic run, [you should start here](https://www.librarycatalogue.act.gov.au/cgi-bin/spydus.exe/FULL/OPAC/ALLWRKENQ/236650476/43663765,2). I'm serious. Go read it.

Ok, so first thing's first: We can't call it Object. Object is such an important word in programming and game dev, that it would just be too confusing. I've gone with Holdable, and it's the word I'll be using going forward.

Second, you may notice that most of this code isn't super needed. But it's there so we can set a **shrink_scale** for individual objects, making them smaller when we carry them
>[!TIP]- Do you like explanations?
	>When I was testing, I found that I kept running into problems that sometimes objects would be the size I want them in the world, but when I pick them up, weird collider stuff happens because the object would try to take up the same space as the ProtoController's body.
	>So we shrink the object!
	>By default, the shrink_scale is just (1,1,1), which doesn't shrink it at all; but any object we attach this script to, we can shrink down so it fits neatly.

For Suzanne, you should set the shrink_scale to (0.2, 0.2, 0.2)

## Part 3 - Editing the Raycasting Clicker script
So now we have our ~~objects~~ *holdables* set up, now our player needs to be able to actually hold them. For this, we're going to make some edited to our **clicker.gd** script

```gdscript
extends RayCast3D
class_name PlayerClicker

@export var hold_point: Marker3D
var held_item : Holdable

func _input(event):
	if event.is_action_pressed("click"):
		if is_colliding():
			var body = get_collider()
			if body is Interactable:
				body.interact()
			elif body is Holdable:
				pick_up(body)
	
	if event.is_action_released("hold"):
		if held_item:
			drop()
		
func pick_up(body):
	held_item = body
	body.reparent(hold_point)
	held_item.global_position = hold_point.global_position
	held_item.freeze = true
	body.shrink()

func drop():
	held_item.embiggen()
	held_item.reparent(get_tree().current_scene)
	held_item.freeze = false
	held_item = null

```

Great, let's break it down:
- **Input** - When our script sees an input, we're going to check if:
	- It's a mouse button **press**, and if the raycast is colliding with something
		- Then, we'll check if that object is an Interactable or a Holdable
			- If it's a holdable, we run the **pick_up** function
	- If it's a mouse button **release**
		- If it is, and we're holding something, we're going to **drop** that item
- **pick_up**
	- Set our held_item variable to that object
	- Reparent the object so it will now be a child of our *hold_point*
	- Set it's position to the *hold_point*'s position as well
	- Set *freeze* on the object to turn it's gravity and velocity off
	- Run the Shrink function on the body too, so it's nice and small to hold
- **drop**
	- Basically undo everything we did in the **pick_up** function

For the final piece of setting up, you just need to make sure you go to the Raycast3D, and assign the **hold_point** Marker3D at the top-right of the inspector!
