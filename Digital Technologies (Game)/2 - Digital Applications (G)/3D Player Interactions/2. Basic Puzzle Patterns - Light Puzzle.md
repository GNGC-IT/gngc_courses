## The Light System
Let's take a look at how I built my Light System.
![[Light_System.png]]
1. I opened up a new scene to build it in. Renamed the root node Light_System
2. Created a CSG Box
	1. Set the size to (1, 0.2, 1)
	2. Set the position to (0, 0.1, 0)
	3. Gave it a nice dark, but shiny material (we want the light above to shine on it 😊)
3. Added an Area 3D
	1. Gave the Area 3D a Collision Shape
	2. Set the shape to just be a box, positioned the box above the trigger platform!
4. Added an OmniLight3D
	1. Set the colour to Red
	2. Set the position to (0, 2, -1) so it's sitting above, but a little set back from the platform
		- We want the player to be able to look at it while they're interacting!

## Scripting the Light System
The script is a great mix of fun, and not too wild!
Add the script to the root node of the Light System scene:

```gdscript
extends Node3D

@export var colours : Array[Color]
var index = 0

@onready var light = $OmniLight3D

@export var door_anim : AnimationPlayer

func _ready():
	light.light_color = colours[index]

func _on_area_3d_body_entered(body):
	if body.name == "ProtoController":
		index += 1
		if index >= len(colours): index = 0
		light.light_color = colours[index]
		
	if index == 4:
		door_anim.play("open")

```

1. So, we've made an array of colours, but we've just exported the array!
	1. This means we get to create the colours in the editor, which is **way better**
	2. I've kept mine simple, with just the primary and secondary light colours (in rainbow order of course)
	3. You can see that #4 here is the Blue (not Cyan), keep that in mind for later in the script
![[Colour_setup.png]]
2. Our other variables are
	1. Index, for keeping track of which light colour we're on
	2. Light, for referencing the OmniLight
	3. door_anim, for triggering the door's animation 
		- Oh yeah, I'm just reusing this from the previous page, check it out here if you need it [[1. Puzzle Patterns - Key-Lock#A *DOOR*]]]
3. When our script starts, we're just going to make sure we're showing the colour to match our starting index value
4. Now we have our Area 3D Body Entered function
	1. The first if statement is handling the colour change when the player walks onto the trigger plate
		1. It even makes sure that we loop through our colours!
	2. The second if statement, is going to open the door when the player changes the light to Blue!

Make sure that you have **linked the Area 3D's Body Entered signal**, and make sure once you add the system to your scene that you also **assign the Door Anim** variable too!
