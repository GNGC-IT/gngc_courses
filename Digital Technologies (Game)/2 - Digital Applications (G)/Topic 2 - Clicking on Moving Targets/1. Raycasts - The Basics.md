# A basic script for testing a Raycast
There's a lot you can do with a raycast!
- Clicking on interactable objects (as explored in the 3D Player Interactions guides)
- Checking if an object is within direct line of sight
- Firing a gun
- Commanding troops in an RTS or similar

We're probably going to be building this into a First-Person Shooter game later down the track, but for now, we're going to just find out some basic information for anything that happens to come across the middle of our screen.

Before we start programming, please add a **label** to your scene as well. I've just added it next to the crosshair. This is going to be printing the name of anything that we look at!
![[my example.png]]

Ok, let's look at the script now:
```gdscript
extends RayCast3D

@onready var infoLabel : Label = $"../../../../Label"

func _physics_process(delta):
	if is_colliding():
		infoLabel.text = get_collider().name
	else:
		infoLabel.text = ""

```

So that's my script! It's very simple, it's just designed to hover over objects, and show you the name of them on the Label :)
